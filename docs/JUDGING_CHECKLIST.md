- [ ] Spot-check three flare rows in `js/data/nasa-data.js` and `js/data/storms.js` against https://kauai.ccmc.gsfc.nasa.gov/DONKI/ and say so in the pitch if a class is from news, not DONKI.
- [ ] Host the game publicly (GitHub Pages: upload the folder, enable Pages) and confirm the README link.
- [ ] Record the 30 s video (`VIDEO_30s.md`): English subtitles, public link, no login.
- [ ] Practise the 240 s pitch (`PITCH_240s.md`) under 4:00; replace every [bracket].
